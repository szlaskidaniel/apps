---
name: No em dashes in descriptions
description: User wants single hyphens (-) instead of em dashes (—) in all text content
type: feedback
---

Always use a single hyphen (-) instead of em dashes (—) or double dashes (--) in descriptions and text content.

**Why:** User preference for cleaner, simpler punctuation style across all app pages.

**How to apply:** When writing any text content (descriptions, alt text, titles, privacy policies), use ` - ` instead of ` — ` for separating clauses.
